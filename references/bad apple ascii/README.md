# Bad Apple on the Tandy

# Running

GitHub repository: [bad-apple-ascii](https://github.com/jarboer/bad-apple-ascii)

Use `make-ascii` to generate the ASCII frames

Then use `tandy200.py` to convert the ASCII frames to basic for the Tandy.

E.g. `python3 tandy200.py frames-ascii --max-bytes 1000` will generate the first 1000 bytes.

# Info

The "tandy" folder has the basic files for the Tandy.
